# Relatórios e evidências

Saídas de execução estão em `generated/`, ignorado pelo Git. `generated/latest.json` indica a execução mais recente. `evidence/` contém somente resultados agregados e capturas revisadas para publicação. Dados individuais e modelos não são publicados. Veja `docs/validacao.md` para commits, comandos e limites das verificações.
